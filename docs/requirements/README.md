## 项目定位

> 一个面向个人开发者和小型团队的**轻量级大模型使用监控与智能分析平台**。

以 **Project（项目）为核心**组织监控数据：用户进入平台先看到"我是谁、我有哪些 AI 项目"，点击项目才进入该项目的监控中心。

------

## 数据流向

```text
AI 项目（接入方）
   ↓ 每次调用大模型后，HTTP 上报
监控平台
   ↓ 按 API Key 归属到项目
数据库
   ↓ 聚合统计
项目监控中心 / AI 分析助手
```

------

## 五条不可违反的设计约束

这五条贯穿所有模块，开发时任何一处违反都会导致设计崩塌：

1. **项目隔离** —— 所有监控数据通过 `project_id` 归属；查询必须带 `project_id` 过滤
2. **用户隔离** —— 项目的归属通过 `Project.owner_id`；涉及项目的查询必须校验归属，硬边界是 `user_id`
3. **AI 不猜数据** —— 所有数字必须来自数据库查询工具，包括项目 ID
4. **AI 不越权** —— 工具参数的权限校验写在**代码**里，不写在提示词里
5. **上报不阻塞业务** —— 监控平台不可用时，接入方的 AI 项目必须照常运行

## 技术栈

```text
后端    Python 3.11+ / FastAPI / Pydantic / SQLAlchemy
数据库  PostgreSQL / Redis
前端    Vue 3 / TypeScript / Vite / Ant Design Vue / ECharts
AI      OpenAI Compatible API + Tool Calling + LangChain
部署    Docker / Docker Compose
```

**架构形态**：V1 采用**模块化单体**，不做微服务。
