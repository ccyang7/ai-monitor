# 项目设置与 Key

## 项目信息

在「项目信息」卡片右上角点击「编辑」，可修改**名称、描述、技术栈**。

- 项目名在同一账号内不能重复
- 描述与技术栈可清空（清空后保存将移除对应内容）
- **修改这些信息不影响已有数据**：调用记录关联项目 ID 而非名称，历史记录、统计与 API Key 均不受影响

## API Key 管理

「API Key」卡片管理接入凭据：

- 一个项目可创建多把 Key（例如用于不同环境）
- 点击「新建 Key」生成新的 Key，**明文同样仅显示一次**
- 每把 Key 显示前缀（`proj_a1b2…`）与创建日期；**已吊销的 Key 不会显示在列表中**

> ⚠️ **吊销立即生效**：使用旧 Key 上报的代码会立即开始收到 401。

> **推荐的换 Key 顺序**（服务不中断）：① 新建一把 Key → ② 更新接入方配置并重启接入方 → ③ 确认新 Key 上报成功 → ④ 吊销旧 Key。

更换 Key 后需**重启接入方进程**，新的环境变量才会生效。未重启时会出现「配置已修改但仍返回 401」的情况。排查方法见 [错误码与处理](/docs/api/errors#401key-的四种失败原因不区分)。

## 删除项目

页面底部的红色区域可删除项目，该操作**不可撤销**：

- 删除需**手动输入项目名**确认，输入正确后「永久删除」按钮才可点击
- 删除后，该项目的调用记录、统计数据与 API Key 一并删除，接入方会立即收到 401
- 删除会**释放一个项目名额**（每个账号最多 3 个活跃项目）

> 当前版本不提供回收站与恢复功能。如仅需暂停使用，停止接入即可，无需删除项目。
