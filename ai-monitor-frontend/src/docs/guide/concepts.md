# 基础概念

本页介绍阅读平台页面所需的基础概念，更多术语见文末的术语表。

## Token：模型的计量单位

Token 是模型处理文本的计量单位，不等于字数；具体切分方式由模型厂商的分词方式决定，中文通常 1 个汉字对应 1~2 个 Token。

页面上展示三档 Token：

- **输入 Token**：发送给模型的内容（提示词、上下文）
- **输出 Token**：模型返回的内容
- **总 Token**：输入与输出之和

> ⚠️ **Token 与 API Key 不是同一概念**：API Key 是接入凭据，Token 是计量单位。

## 缓存命中：输入 Token 中按低价计费的部分

部分厂商（如 DeepSeek）对重复出现的输入前缀收取较低价格。输入 Token 因此分为两档：

- **命中**（命中缓存）：按缓存命中价计费
- **未命中**：按输入价计费

> ⚠️ **「命中 + 未命中 = 输入」**。缓存命中是输入 Token 的内部拆分，不是额外的第三项，计算成本时不应重复累加。

缓存命中情况可在调用日志的「缓存命中」列与详情抽屉中查看。

## 预估成本：是估算，不是账单

```text
成本 = 各类 Token ÷ 100 万 × 该模型的单价
```

单价来自「模型管理」中的价格表。平台按**模型名**匹配价格，未配置价格的模型无法计算成本，页面显示「—」。

页面上的费用称为「**预估**费用」，原因有两点：

1. **Token 数量来自厂商返回的用量**，厂商的计数本身存在偏差
2. **价格是写入时的快照**：每条记录的成本在上报时按当时的价格计算并保存，之后修改价格不会重算历史记录

> ⚠️ **「—」与「¥0.00」含义不同**：
>
> - `—`：未匹配到价格，无法计算
> - `¥0.00`：已计算，结果为 0（如免费模型）

## 基线：判定「异常」的参照物

平台的异常判定基于与基线的对比：同一项目、同一模型最近 7 天成功调用的平均 Token 与平均耗时。

基线按项目与模型分别计算。推理模型与轻量模型在 Token 用量和耗时上差异较大，混合计算会使基线失去参考意义。

详见 [异常分析](/docs/guide/anomalies)。

## 环比：与上一等长周期对比

概览页每张统计卡都带有环比。环比的计算方式是：取所选区间，再往前取一个等长区间进行对比。

- 选「今日」：与昨日对比
- 选「近 7 天」：与再往前 7 天对比（不是自然周）
- 选「近 30 天」：与再往前 30 天对比

变化小于 **5%** 时不显示环比，以免产生噪声。

## 术语表

| 术语 | 说明 |
| --- | --- |
| 项目 | 平台的数据隔离单位，一个 AI 项目对应一个平台项目 |
| API Key | 接入方上报数据的凭据，明文仅在创建时显示一次 |
| 上报 | 将 AI 项目的每次模型调用发送至平台的操作（一次 POST 请求） |
| 调用记录 | 一次模型调用在平台上的记录 |
| Token | 模型处理文本的计量单位，分输入、输出、总 Token |
| 缓存命中 | 输入 Token 中命中缓存的部分（子集），按缓存命中价计费 |
| 预估成本 | 按价格表计算的估算金额，写入时快照，不是账单 |
| 环比 | 与上一个等长周期的对比（近 7 天比前 7 天） |
| 基线 | 同项目同模型近 7 天成功调用的平均水平，异常判定的参照物 |
| 判定标准 | 四类异常的阈值，可「跟随默认」或固定为自定义值 |
| 样本不足 | 近 7 天成功调用少于 10 次时暂不判定，不代表正常 |
| 内置模型 | 平台预置的全平台共享价格 |
| 自建模型 | 自行新增的价格，仅自己可见 |
| 在用的项目 | 按上报的模型名匹配出的使用该模型的项目 |
| 全部时间 | 调用日志页的时间选项，不限时间范围 |
| 趋势粒度 | 趋势图按天或按小时出点；「今日」按小时，其余按天 |
| 上下文标签 | 助手面板上「当前项目：X」的提示，仅作提示 |
| 只读 | AI 助手不能修改任何数据 |
