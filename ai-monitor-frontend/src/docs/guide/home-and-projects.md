# 首页与项目

## 首页展示的内容

首页展示账号下的项目列表以及每个项目的当前状态，不汇总所有项目的 Token 用量与费用。跨项目的对比与汇总可通过 [AI 助手](/docs/guide/ai-assistant) 查询。

## 项目卡片

每张卡片包含四项信息：**项目名、状态、技术栈、最近调用时间**。状态有三种：

| 状态 | 含义 |
| --- | --- |
| **未接入数据**（灰） | 该项目尚未上报任何记录 |
| **正常**（绿） | 有数据，且最近 7 天未检出异常 |
| **有异常**（橙） | 最近 7 天检出异常，可进入项目查看「异常」页 |

> ⚠️ **「未接入数据」有两种成因**：
>
> 1. 项目刚创建，接入代码尚未完成
> 2. 已接入但未成功上报，请按 [接入验收清单](/docs/getting-started/verify) 检查，排查方法见 [错误码与处理](/docs/api/errors)

> ⚠️ **「正常」表示最近 7 天未检出异常，不代表不存在问题**。判定规则见 [异常分析](/docs/guide/anomalies)；样本不足时页面会显示「数据还在积累」，而非「正常」。

卡片底部的「最近调用」显示最后一次调用的时间（`刚刚` / `N 分钟前` / `N 天前` / 具体日期）。

## 新建项目

点击首页末尾的虚线卡片「创建项目」，填写名称、描述（选填）与技术栈。

限制如下：

- **每个账号最多 3 个活跃项目**。达到上限后创建请求会被拒绝，删除不用的项目可释放名额，见 [删除项目](/docs/guide/project-settings#删除项目)
- **同一账号下项目名不能重复**
- 项目名最多 100 个字符

创建成功后，弹窗显示「项目已创建」，并展示 **API Key 明文**。

> ⚠️ **API Key 明文仅显示一次。** 平台仅存储其 SHA-256 哈希，无法还原明文。若未保存，请在设置页吊销后重新生成，见 [项目设置与 Key](/docs/guide/project-settings#api-key-管理)。

## 进入项目

点击卡片进入项目页。项目页包含四个子页：

| 子页 | 内容 |
| --- | --- |
| [概览](/docs/guide/overview) | 项目当前的用量、成本与状态 |
| [调用日志](/docs/guide/logs) | 单次调用的详细信息 |
| [异常](/docs/guide/anomalies) | 检出的异常事件 |
| [设置](/docs/guide/project-settings) | 修改项目信息、管理 API Key、删除项目 |
