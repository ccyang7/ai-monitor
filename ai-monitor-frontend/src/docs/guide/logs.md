# 调用日志

## 调用日志页的用途

调用日志页用于从汇总数据下钻到单条记录，常见用途：

- 核对某条调用的费用
- 查看某次调用失败的原因
- 查看某次调用的提问与回答原文
- 确认某次调用的发生时间

## 筛选与搜索

| 控件 | 选项 |
| --- | --- |
| 模型 | 全部模型 / 上报过的各个模型名 |
| 状态 | 全部状态 / 成功 / 失败 |
| 时间范围 | **全部时间**（默认）/ 今日 / 近 7 天 / 近 30 天 / 自定义范围 |
| Token | Token 不限 / 小于 1 千 / 1 千 ~ 1 万 / 大于 1 万 |
| 搜索框 | 按**提问内容、回答内容、模型名**搜索（不区分大小写） |

- 多个条件需**同时满足**（AND）
- 搜索在输入停顿约 0.3 秒后自动发起，无需回车
- 右侧「重置」可清空全部条件

调用日志页的时间范围包含「全部时间」，不设 30 天上限；概览页面向汇总结果，跨度上限为 30 天。

两个常用筛选组合：

- 查找「上周失败且 Token 较多的调用」：状态选**失败**，选择自定义时间范围，Token 选**大于 1 万**
- 查找「回答中包含某个词的调用」：在搜索框输入该词

## 列表字段

| 列 | 说明 |
| --- | --- |
| 时间 | 调用**发生**的时间 |
| 模型 | 上报的模型名 |
| 输入 Token | 发送给模型的 Token 数量 |
| **缓存命中** | 输入 Token 中命中缓存的部分；模型未配置缓存价或接入方未上报时为 0 |
| 输出 Token | 模型返回的 Token 数量 |
| 总 Token | 输入与输出之和 |
| 耗时 | 毫秒，超过 1 秒显示为 `1.5s` |
| 预估费用 | 金额，保留两位小数；不足半分钱显示 `<¥0.01`，模型未配置价格时显示「—」 |
| 状态 | 成功 / 失败 |

> ⚠️ **列表不加载提问与回答正文**。正文体量较大，加载会拖慢翻页，仅在打开详情抽屉时获取。

## 详情抽屉

点击任意一行，右侧滑出**调用详情**抽屉：

- **顶部**：状态、模型、Provider、精确到秒的时间
- **指标区**：输入 / 输出 / 总 Token、响应时间、预估费用。存在缓存数据时，输入 Token 下方显示「**命中 X · 未命中 Y**」
- **失败调用**：红色「错误信息」区域
- **用户提问 / 模型回答**：全文，各带「复制原文」按钮

- 提问或回答为 **JSON 格式**时，抽屉将其结构化渲染；内容较长时折叠，可「展开全部 N 字」
- 「复制原文」复制的是未渲染的原始内容
- 仅上报指标、未上报正文时，抽屉显示「这次调用只上报了指标，没有记录提问内容」

> ⚠️ **关闭抽屉后，筛选条件与页码保持不变**，无需重新筛选。

失败调用通常没有提问与回答：超时、限流等失败发生在模型返回之前，接入方无法取得内容，上报时仅有指标。

## 分页与排序

- 每页 20 条，最新的记录排在前面
- 按「调用**发生**的时间」排序，补报的历史数据会落在对应位置

> `timestamp` 传入错误时，记录在列表中的位置也会错误，且从记录内容上无法察觉。时区规则见 [上报接口](/docs/api/ingest#时间规则)。
