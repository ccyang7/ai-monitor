# 项目概览

## 概览页展示的内容

概览页将项目的当前状态汇总为一屏，包含五个方面：**调用次数、Token 用量、费用、平均响应时间、异常情况**。日常巡检查看本页即可；需要查看具体记录时，请前往 [调用日志](/docs/guide/logs) 与 [异常](/docs/guide/anomalies)。

## 选择时间范围

页面右上角的时间选择器提供四个选项：**今日 / 近 7 天 / 近 30 天 / 自定义范围**。

- 「近 7 天」「近 30 天」均为含今天的自然日
- 选择「今日」时，趋势图按小时出点；其他范围按天
- 选择「自定义范围」需填写起止日期，跨度上限 30 天

更长的时间范围请在 [调用日志](/docs/guide/logs) 页查看，该页不限制跨度。

图表说明文字与粒度对应：按天时注明「没有调用的日子按 0 计」，按小时时注明「没有调用的小时按 0 计」，数据断档不会截断图表。

## 简报条

页面顶部的彩色横幅以一句话概括当前区间的关键指标，例如：

> 近 7 天调用 **1,240** 次，比上一周期多 **32%**。Token 用了 **186 万**，**78% 集中在 deepseek-chat**。**3** 次调用失败，建议看一眼。 查看异常 →

横幅颜色表示严重程度，共四档：

| 颜色 | 含义 |
| --- | --- |
| **红** | 存在失败调用或错误率偏高 |
| **橙** | 存在 Token 突增或响应变慢 |
| **绿** | 未发现问题 |
| **灰** | **数据还在积累，暂未开始判定** |

> ⚠️ **灰色与绿色含义不同。**「数据还在积累」表示尚未开始判定，不代表没有异常。新接入的项目在最初几天出现灰色简报条属正常现象，右侧「查看进度 →」会显示距离开始判定还差多少，见 [样本不足](/docs/guide/anomalies#样本不足-vs-没有异常)。

简报条的生成规则：

- 环比变化小于 **5%** 时不显示
- 单个模型占比达到 **70%** 以上时显示「集中在 XX 模型」，否则显示「分布在 N 个模型上」
- 仅显示实际发生过的异常类型
- 右下角「数据更新于 HH:MM」为本次查询的时间

## 统计卡

| 卡片 | 显示 | 角标（有则显示） |
| --- | --- | --- |
| **调用次数** | 区间内调用总数与环比 | 有失败或错误率异常时：**异常 N**（红） |
| **总 Token** | 输入与输出总量及环比 | Token 异常时：**偏高 N**（橙）；样本不足时：**样本不足**（灰） |
| **预估成本** | 金额与环比 | 无角标 |
| **平均响应** | 平均耗时与环比 | 响应异常时：**偏慢 N**（橙）；样本不足时：**样本不足**（灰） |

成本由 Token 推导，相关异常已在总 Token 卡上标注，因此预估成本卡不带角标。

> ⚠️ **角标颜色表示是否需要关注，不表示升降方向。** 成本上涨显示橙色角标，而环比「下降 32%」显示绿色。

> ⚠️ **区间内没有成功调用时，平均响应显示「—」而非 0。**

角标中的数字为区间内该类异常的数量，与异常页筛选后的条数一致，点击可查看对应记录。

## Token 用量趋势

按天（或按小时）展示柱状图，用于判断 Token 用量是否持续上升。悬停可查看具体数值。

## 成本趋势与模型使用占比

下方并列两个区块：

- **成本趋势**：与 Token 趋势对照阅读。用量上升而成本基本不变，通常表示使用了价格更低的模型；用量不变而成本上升，通常表示使用了价格更高的模型或输出变长
- **模型使用占比**：右上角可切换三个口径：**调用次数 / Token / 成本**

> 同一模型在三个口径下的排名可能不同：调用次数最多的一般是价格较低的常用模型，成本最高的可能是调用频率低但单价高的推理模型。查看成本时建议切换到「成本」口径。切换口径后列表会按新口径重新排序。
