# 接入验收清单

接入完成后，请逐项完成以下检查。五项全部通过，视为接入完成。

| # | 操作 | 期望结果 |
| --- | --- | --- |
| 1 | 上报一条记录，进入平台「调用日志」页 | 最新一条为刚上报的记录，模型与耗时一致；首页卡片由「未接入数据」变为「最近调用 刚刚」 |
| 2 | 查看「预估费用」列 | 显示金额（**包括 `¥0.00` 与 `<¥0.01`**）表示模型名匹配成功；显示「—」表示未匹配价格表 |
| 3 | 对比记录时间与当前时间 | 一致表示时区正确；**相差 8 小时**表示 `timestamp` 传入的是不带时区的本地时间 |
| 4 | **关闭平台，重新运行一次 AI 项目** | **业务正常完成**，此项为必测项 |
| 5 | 上报一条 `status="error"` 的记录 | 列表显示红色「失败」标签，点击该行可在详情抽屉中查看错误信息 |

## 第 4 项

第 4 项用于验证上报实现不会阻塞业务。如果该项未通过，请检查 [把上报写进代码](/docs/getting-started/integration) 中的实现：是否使用了同步调用，或超时设置是否过长。

## 第 2 项显示「—」

进入「模型管理」页。已上报但价格表中无匹配价格的模型会显示在页面顶部的橙色提示条中，并标注所属项目。点击模型名可打开预填表单，核对价格并保存后提示条消失。详见 [模型与价格](/docs/guide/models)。

显示 `¥0.00` 与显示「—」含义不同：前者表示价格匹配成功且该模型实际免费，后者表示未找到价格。金额大于 0 但不足半分钱时显示 `<¥0.01`，同样表示价格匹配成功。

## 第 3 项

第 3 项是验收中唯一能够发现时区错误的方法。时区错误不会导致请求失败，只会使所有记录的时间偏移 8 小时，且在列表中无异常表现。规则说明见 [上报接口的时间规则](/docs/api/ingest#时间规则)。

## 数据还在积累

接入初期，概览页与异常页可能显示「数据还在积累」，属于正常状态：异常判定需要在同一模型下累积足够样本后才会启用。该状态与「没有异常」不同，页面以灰色和绿色区分，详见 [异常分析](/docs/guide/anomalies)。

## 接入完成后

概览页的四张统计卡与趋势图将显示数据，调用日志页可查看刚上报的记录。如需进一步了解页面指标，请阅读「使用指南」。
