# 功能与账号

## 异常分析

### 显示「数据还在积累」是不是功能故障？

不是。近 7 天该模型的成功调用少于 10 次时暂不判定。页面会显示距开始判定还差的次数，样本足够后自动开始判定。详见 [异常分析](/docs/guide/anomalies#样本不足-vs-没有异常)。

### 调整阈值后列表数量明显变化？

属预期行为。判定标准在查询时套用，修改后历史数据立即按新标准重新判定。

### 为什么部分异常卡片不可点击？

「错误率偏高」类型的卡片不可点击，该类型描述某一天的整体情况，没有对应的单次调用。

### 同一次调用为什么出现两条异常？

该次调用同时触发两个阈值（例如耗时与 Token 均超限），两条异常指向同一条日志。

### 平台会误报吗？

判定阈值设置偏保守，样本不足时不判定。如需核对，可展开判定标准卡查看规则。

## AI 助手

### 助手返回的数字可靠吗？

可靠。回答中的每个数字均来自对你账号数据的实际查询，查询过程通过「正在查询…」状态显示。

### 能让助手修改价格或删除项目吗？

不能。助手为只读，此类操作需在页面上手动完成。

### 为什么回答较慢？

复杂问题通常需要连续执行多轮数据查询（对比类问题可能需要 3~5 次）。生成过程中可点击「停止」。超过查询轮数上限时会提示「分析超时，请换个问法」，更具体的问题通常更快返回。

### 助手能看到其他项目或其他用户的数据吗？

你账号下的全部项目均可查询（包括跨项目对比）；其他用户的数据不可查询，权限校验在代码中实现。

## 账号与项目

### 项目数量上限是多少？删除后能再建吗？

最多 3 个活跃项目。删除项目会释放名额，见 [删除项目](/docs/guide/project-settings#删除项目)。

### API Key 忘记或泄露怎么办？

遗忘：在设置页吊销并新建一把 Key（仅新 Key 显示明文）。泄露：同样吊销，吊销**立即生效**，接入方会开始收到 401，更换新 Key 即可。推荐顺序见 [API Key 管理](/docs/guide/project-settings#api-key-管理)。

### 为什么一段时间后需要重新登录？

登录状态有效期为 7 天，到期后需重新登录。

### 可以修改或找回密码吗？

当前版本不支持自助修改密码与找回密码功能。
